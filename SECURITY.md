# Security

Please do not report security problems in a public issue.

Use GitHub's private vulnerability reporting on this repository (Security → Report a
vulnerability). We acknowledge reports within three working days and tell you what we intend to do
and when.

In scope: anything in a published `@eldrajs/*` package from this repository. The rich text
renderer serialises merchant-authored content into HTML, so an escaping gap there is the report we
most want to hear about. The Eldra platform itself (the APIs these packages call) has its own
disclosure route; if you are unsure which applies, use this one and we will route it.
